Sistema de dungeons instanciadas para Paper, em Kotlin, integrado ao [Typewriter](https://typewritermc.com/)
para montar dungeons, eventos e diálogos sem código.

## Destaques

- Instâncias por grupo com clonagem de mundo e geração procedural de salas.
- Party com chat, ready check, fila e votação de dificuldade.
- Vidas, modo espectador, armadilhas, chaves, modificadores e dungeon diária.
- Cutscenes, conquistas, estatísticas, leaderboard e progressão.
- Integrações: MythicMobs, MMOCore, Vault.
- Entradas do Typewriter (ações, eventos, fatos, audiências) para os designers usarem.

## Stack

Kotlin · Gradle (Kotlin DSL) · Paper API · Typewriter · MythicMobs

## Como compilar

```bash
./gradlew build
```
